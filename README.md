# Labyrinth
## Описание проекта
Проект представляет собой программу, способную генерировать лабиринты с использованием алгоритмов DFS или минимального остовного дерева, а также находить путь через лабиринт от начальной до конечной точки. Пользователь сможет выбирать тип генерации лабиринта, сохранять и загружать созданные лабиринты, а также просматривать решение.

## Реализуемый функционал
1. Генерация лабиринта с помощью DFS или минимального остовного дерева (выбор метода через аргумент командной строки).
2. Отображение лабиринта в графическом интерфейсе.
3. Сохранение и загрузка лабиринтов в/из файлов.
4. Решение лабиринтов и отображение пути от начальной до конечной точки.

## Архитектура
### Классы:
1. Generator - класс для генерации лабиринтов с методами:
   - matrix - двумерный массив, представляющий структуру лабиринта
   - track - массив представляющий решение лабиринта
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   
2. GeneratorDFS наследуется от Generator - класс для решения лабиринтов с методами:
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   - DFS() - алгоритм генерации лабиринта
   
3. GeneratorMST наследуется от Generator - класс для решения лабиринтов с методами:
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   - MST() - алгоритм генерации лабиринта
   
4. Labyrinth - класс для представления самого лабиринта:
   - generator - объект генератор лабиринта
   - draw() - отрисовка лабиринта
   
5. Loader - класс загрузки и выгрузки лабиринтов в файл:
   - import() - импорт лабиринта
   - export() - экспорт лабиринта
