# Labyrinth
## Описание проекта
Проект представляет собой программу, способную генерировать лабиринты с использованием алгоритмов DFS или минимального остовного дерева, а также находить путь через лабиринт от начальной до конечной точки. Пользователь сможет выбирать тип генерации и размер лабиринта, проходить его с помощью клавиатуры, а также просматривать решение.

## Реализуемый функционал
1. Генерация лабиринта с помощью DFS или минимального остовного дерева (выбор метода из меню).
2. Отображение лабиринта в графическом интерфейсе.
3. Возможность проходить лабиринт с помощью клавиатуры.
4. Отображение пути от начальной до конечной точки.

## Архитектура
### Классы:
1. Generator - класс для генерации лабиринтов с методами:
   - matrix - двумерный массив, представляющий структуру лабиринта
   - track - массив представляющий решение лабиринта
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   
2. GeneratorDFS наследуется от Generator - класс для решения лабиринтов с методами:
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   - DFS() - алгоритм генерации лабиринта
   
3. GeneratorMST наследуется от Generator - класс для решения лабиринтов с методами:
   - update() - обновеление лабиринта
   - generate() - генерация лабиринта
   - find_track() - поиск пути в лабиринте
   - MST() - алгоритм генерации лабиринта
   
4. Labyrinth - класс для представления лабиринта:
   - generator - объект генератор лабиринта
   - draw() - отрисовка лабиринта

5. Player - Класс реализует перемещение игрока по лабиринту:
   - update() - обновление положения игрока
   - up(), down(), left(), right() - перемещение игрока
